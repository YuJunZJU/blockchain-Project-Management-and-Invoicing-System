# 组员部署包

这是一个可在新 Ubuntu、WSL2 Ubuntu 或 Linux 虚拟机上独立部署的课程演示包。

请先打开项目内的 [组员部署与快速上手手册.md](组员部署与快速上手手册.md)，并严格按“首次独立部署”章节执行。首次部署需要依次运行：

```bash
./scripts/start-network.sh check
./scripts/start-network.sh init
./scripts/deploy-chaincode.sh
./scripts/start-app.sh
```

本包已包含未初始化的 `fabric-runtime/` 模板，因此可以在新电脑执行 `init` 创建自己的测试网络。包内不包含组长电脑的旧账本、旧通道、旧证书、已注册账户文件或已打包链码。

`.env` 中包含课程演示使用的 OCR 配置，仅限小组内部使用；请不要上传 GitHub、转发到公共群或放进报告、截图。
