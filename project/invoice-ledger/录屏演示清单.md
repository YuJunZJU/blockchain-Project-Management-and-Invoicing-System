## 推荐录制顺序

### 1. 开场与已有数据

1. 打开 `http://localhost:8080`。
2. 使用 `alice / alice123` 登录。
3. 展示当前身份、首页统计、组织名录和两个项目。
4. 打开“实验室设备采购项目”，说明已支付、剩余额度回收和链上事件。

### 2. 现场创建一条完整主流程

使用 Alice 创建：

```text
项目名称：区块链发票管理系统建设项目
项目内容：开发基于 Hyperledger Fabric 的项目管理、发票存证、流转核验和报销支付系统。
项目预算：10000 元
预计结项日期：2026-12-31
```

然后按以下顺序切换账号：

```text
Alice 保存并提交立项
→ project-reviewer 通过立项
→ Alice 提交结项材料
→ project-reviewer 通过结项并发放额度
→ Alice 使用保留 PDF 完成 OCR 和发票存证
→ Alice 创建报销单
→ project-reviewer 审核报销单
→ finance-admin 确认支付
→ 查看项目资金池和统计变化
```

审核意见建议提前复制：

```text
立项审核：项目目标明确，技术路线合理，预算符合课程实践要求，同意立项。
结项审核：系统功能和实验材料完整，同意通过验收并进入财务结算。
报销审核：发票信息、采购用途和项目材料一致，同意报销。
```
