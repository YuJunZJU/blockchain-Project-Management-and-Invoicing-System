# 业务组织管理说明

## 两层“组织”

本次新增的是**业务组织目录**，用于在应用中登记和展示学校、总部、内部项目组、外部财务或合作单位。组织档案会写入 Fabric 账本。

它和 Fabric 的技术组织不是同一概念：当前课程网络仍只有 `Org1MSP` 与 `Org2MSP` 两个技术组织、两个 Peer。网页登记一个外部公司，并不会自动在 Docker 中创建该公司的 Peer、CA、MSP 或独立证书。

## 三类业务组织

| 类型 | 用途 | 上级组织 |
| --- | --- | --- |
| 主体组织 | 学校、总部、牵头单位 | 无 |
| 公司内部项目组 | 某主体组织下的项目执行团队 | 必须选择已登记的主体组织 |
| 外部协作组织 | 财务共享中心、合作企业、供应商等 | 无 |

## 使用方法

1. 使用 `org-admin / orgadmin123` 登录，或注册岗位为“组织管理员”的账号。
2. 在左侧进入“组织管理”。
3. 先登记一个主体组织，例如“浙江大学”。
4. 再登记内部项目组，并选择该主体组织作为上级组织。
5. 根据需要登记外部协作组织，例如“某财务服务中心”。

所有登录用户均可查看组织目录，只有组织管理员可以新增组织。每次登记会保存组织名称、类型、上级主体、说明、登记人、登记时间及所选 Fabric 接入节点。

## 当前边界与后续扩展

注册业务用户时，用户直接选择已登记的业务组织；系统会读取该组织绑定的 `Org1MSP` 或 `Org2MSP`，再使用相应测试证书提交登记交易。成员名录会同时展示业务组织和底层接入节点。

若以后要让新增外部组织真正成为联盟链节点，需要由网络管理员在 Fabric 层额外完成 CA 注册、证书签发、Peer 部署、通道加入、锚节点与背书策略更新；这属于网络运维流程，不适合直接开放给普通网页用户执行。
